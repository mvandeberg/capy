Generated by the Phase 0 / Task 1 re-baseline (`docs: re-baseline review feedback against
develop`) against `DOC_REVIEW_FEEDBACK.md` Section 2. One row per finding that is still

**Legend**
- `surface` — `adoc` (exposition pages under `doc/modules/ROOT/pages/**`), `docstring`
  (Doxygen comments in `include/boost/capy/**` headers, source for the MrDocs reference),
  or `both`.
- `phase` — maps to `DOC_IMPROVEMENT_PLAN.md`: `1`=Structure, `2`=Accuracy,
  `3`=Completeness/Pedagogy, `4`=Wording, `5`=Corosio (repeat of Phases 0–4 against the
  Corosio repo, not available in this checkout).
- `owner` — `unassigned` for Phase 1–4 rows (picked up task-by-task per the plan);
  `Phase 5` for Corosio-deferred rows (require the Corosio repo checked out).
